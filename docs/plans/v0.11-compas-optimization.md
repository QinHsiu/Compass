## Part B — v0.12.0 Epic：登录态爬岗 + Four-Leaf 级十万岗

竞品锚点：CareerForge 登录态搜索；clover-public / Four-Leaf `search_jobs` 十万级。

### B1. 登录态采集框架（Auth Session Collectors）

| 组件 | 说明 |
|:--|:--|
| `auth_session/` | 本地会话仓：导入 Playwright `storage_state.json` / Netscape cookies；可选 Fernet 加密 |
| `collectors/experimental/auth_boards.yml` | 板级适配声明（host、list URL 模板、字段选择器、rate limit） |
| CLI | `session import --path`；`session status`；`scout --auth --board boss:...`（需双旗标） |
| 门禁 | 无 `--i-accept-tos-risk` → 仍走 blocklist 拒绝；有则仅实验适配器 |
| 时效 | 三层 liveness（已有 posting_liveness）接到登录态结果：URL/标题/过期启发式 |
| 产出 | 写入 `content/jobs/` 与 Job Warehouse，与现有 match/batch 打通 |

首批适配目标（骨架 + 1 个 mock/fixture 板，避免 CI 打真站）：

1. 通用「已登录 HTML list」适配器（CSS/JSON-LD）
2. 可选：用户文档化的板配置示例（Boss/拉勾等仅作配置模板，CI 用 fixture HTML）

### B2. Job Warehouse「十万岗」（Four-Leaf / clover 对标）

| 组件 | 说明 |
|:--|:--|
| 存储 | `content/warehouse/jobs.sqlite`（或 duckdb）：job_id、title、company、location、url、source、fetched_at、raw |
| 摄入 | `warehouse ingest`：ATS boards 并行、CSV/JSONL 导入、auth scout 结果、公开 RSS |
| 检索 | `warehouse search --q --loc --limit`；FTS5 |
| 规模目标 | 架构支持 **≥100k** 行；种子用合成/fixture 验证，真实填充靠用户跑 ingest |
| MCP | `packages/.../mcp` 或 desk：`jobs.search` / `jobs.get` 读本地仓（本地 MCP，非托管竞品库） |
| 薪资 | `comp_lookup`：用户/导入分位表；仍可手填 `market_p50`，可选导入公开数据集文件 |

### B3. v0.12 验收

| 项 | 标准 |
|:--|:--|
| session | 无 risk 旗标 → blocklist 仍拒；有旗标 + fixture → 解析出 N 条 job |
| warehouse | ingest 1万 fixture 行后 FTS 可查；MCP/CLI search 返回 |
| 集成 | warehouse 命中 → `batch` / `match` 可消费 |

## Part C — v0.13.0 Epic：企业级 APM

在 v0.11 `obs alerts` 之上升级为可对接企业栈的可观测面。

| 组件 | 说明 |
|:--|:--|
| OTel | CLI/Web 关键 span（match、scout、warehouse ingest、interview score） |
| Metrics | Prometheus `/metrics`（desk）或 `obs export-prom` 文本 |
| Trace export | 可选 OTLP endpoint（env `OTEL_EXPORTER_OTLP_ENDPOINT`）；**默认仅本地** |
| SLO | `obs slo`：gate_pass_rate、ingest_success、match_p95；写 `logs/slo.json` |
| 仪表约定 | `docs/observability.md`：Grafana 面板 JSON 示例（可选） |
| 隐私 | content/ 路径脱敏；禁用时零外发 |

### C 验收

- `obs status` 显示 otel on/off、最近 spans 计数
- desk 或文件暴露 Prometheus 计数器
- 文档说明如何接到 Grafana / Jaeger
