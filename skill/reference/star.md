# STAR for Compass

Every behavioral answer:

| Letter | Meaning | Must cite |
|--------|---------|-----------|
| S | Situation | optional context |
| T | Task | optional |
| A | Action | `evidence_id` for what you did |
| R | Result | metrics from evidence or `UNVERIFIED` |

Stress follow-ups should attack weak metrics or missing ownership — align with diagnose gaps.
