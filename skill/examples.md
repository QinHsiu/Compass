# Examples

## Intake

```
/intake
目标：后端 / 机器学习平台，上海或远程
年限：3年；可到岗：1个月
忌：纯外包驻场
（粘贴简历原文）
```

## Evidence

```
/evidence
把刚才简历拆成证据条目，指标能量化的单独成条。
```

## Discover + short path

```
/discover
公司：ExampleAI
职位：ML Platform Engineer
要求：Python, Kubernetes, feature store, 有线上事故处理经验优先
...
```

Then:

```
/resume job_id=job_exampleai_mlplat
/interview job_id=job_exampleai_mlplat
/diagnose job_id=job_exampleai_mlplat
```

## Bridge

```
/bridge job_id=job_exampleai_mlplat
针对技能缺口给 2 周可验证补强计划（产出可进 evidence，不写假公司）。
```

## Track

```
/track job_id=job_exampleai_mlplat status=applied note=已发邮件
```
